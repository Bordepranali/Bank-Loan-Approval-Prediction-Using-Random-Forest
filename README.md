# Bank Loan Approval Prediction Using Machine Learning

## Project Overview
This is a Machine Learning Capstone Project that predicts whether a bank loan application is likely to be approved or rejected using a Random Forest Classification model.

## Objectives
- Clean and preprocess loan application data.
- Handle missing values.
- Encode categorical variables.
- Train a Random Forest classification model.
- Evaluate model performance.
- Predict loan approval status.

## Dataset
Kaggle – Loan Prediction Dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook

## Machine Learning Algorithm
Random Forest Classifier.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Project Features
- Data Cleaning
- Feature Engineering
- Categorical Encoding
- Model Training
- Model Evaluation
- Loan Status Prediction
- Model Saving and Loading

## Files Included
- Bank_Loan_Approval_Prediction.ipynb
- loan_prediction.csv
- loan_approval_model.pkl

## Conclusion
A Random Forest classification model was developed to predict loan approval status based on applicant information. The model was evaluated using standard classification metrics.

## Disclaimer
This project is developed for educational purposes only. Predictions are not actual financial or lending decisions.
